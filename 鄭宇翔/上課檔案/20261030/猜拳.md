- 三個按鈕 `input button`
- 點按鈕出拳
  - 取得 dom 按紐 `getElement..` `querySelector...`
  - 綁定 click 事件 `onclick` `addEventListener`
  - 怎麼知道點了哪一個按鈕
- 電腦隨機出拳 `Math.random()`
- 判斷勝負
  - 平手用 `==`
  - 輸或贏只要判斷其中一個，剩下的另一個用 `else`
    ```js
    if (使用者 == 電腦) {
      結果 = 平手
    }
    else if (贏的條件) {
      結果 = 贏
    }
    else {
      結果 = 輸
    }
    ```
- 顯示結果 `alert()`
- 列出紀錄
  - `ul` `li`
  - 取得 ul `getElement..` `querySelector...`
  - 新增 li `createElement` `insert...` `append` `prepend`
